## 4. 用户场景

### 场景 1：老师创建项目里程碑和任务

老师（OWNER/MAINTAINER）进入项目详情 → 切换到里程碑 Tab → 创建里程碑 → 切换到任务看板 → 创建任务 → 分配给学生成员。

### 场景 2：学生从首页进入任务

学生登录 → 首页 tasks 区域看到待办任务 → 点击任务进入项目看板 → 将任务从 TODO 开始为 IN_PROGRESS。

### 场景 3：学生完成任务

学生进入项目看板 → 找到自己的任务 → 标记为 DONE → 首页任务数量同步更新。

### 场景 4：任务阻塞

学生遇到阻塞 → 将任务标记为 BLOCKED 并填写阻塞原因 → 老师在看板看到红色阻塞标签 → 介入解决。

### 场景 5：并发编辑冲突

两个用户同时编辑同一任务 → 后提交者收到 409 VERSION_CONFLICT → 刷新后重新操作。

### 场景 6：观察者只读

OBSERVER 进入项目 → 可以查看里程碑和看板 → 所有创建/编辑/状态变更按钮隐藏。

## 5. 已冻结内容（REVIEW 状态，待确认）

### 5.1 里程碑

- **字段**：id、projectId、name、description、status、startDate、endDate、sortOrder、createTime、updateTime
- **状态**：PLANNED / IN_PROGRESS / COMPLETED（COMPLETED 为终态）
- **状态转换**：PLANNED → IN_PROGRESS → COMPLETED（单向）
- **排序**：sortOrder ASC, id ASC
- **创建权限**：OWNER / MAINTAINER
- **查看权限**：所有项目成员

### 5.2 任务

- **字段**：id、projectId、milestoneId、title、description、status、assigneeUserId、assigneeName、priority、dueDate、blockReason、version、createdBy、createTime、updateTime
- **状态**：TODO / IN_PROGRESS / BLOCKED / DONE / CANCELED
- **终态**：DONE、CANCELED 为终态，不可转换
- **DONE 语义**：负责人提交即完成，不需要额外验收（简单闭环）
- **BLOCKED 规则**：进入 BLOCKED 时 blockReason 必填（2-500 字符）
- **CANCELED 规则**：终态，不允许恢复，默认不在看板显示
- **乐观锁**：version 字段，每次更新自增，冲突返回 409 VERSION_CONFLICT
- **分配规则**：任务只能分配给项目成员，否则 400 ASSIGNEE_NOT_MEMBER

### 5.3 状态转换矩阵

```
TODO → IN_PROGRESS
TODO → CANCELED
IN_PROGRESS → BLOCKED
IN_PROGRESS → DONE
IN_PROGRESS → CANCELED
BLOCKED → IN_PROGRESS
BLOCKED → CANCELED
```

### 5.4 权限矩阵（里程碑与任务）

| 操作 | OWNER | MAINTAINER | MEMBER（负责人） | MEMBER（非负责人） | OBSERVER |
|---|---|---|---|---|---|
| 查看里程碑 | 可 | 可 | 可 | 可 | 可 |
| 创建里程碑 | 可 | 可 | 不可 | 不可 | 不可 |
| 更新里程碑状态 | 可 | 可 | 不可 | 不可 | 不可 |
| 查看任务/看板 | 可 | 可 | 可 | 可 | 可 |
| 创建任务 | 可 | 可 | 待确认 | 不可 | 不可 |
| 编辑任务信息 | 可 | 可 | 不可 | 不可 | 不可 |
| 分配/更换负责人 | 可 | 可 | 不可 | 不可 | 不可 |
| 开始任务 | 可 | 可 | 可（自己的） | 不可 | 不可 |
| 阻塞任务 | 可 | 可 | 可（自己的） | 不可 | 不可 |
| 完成任务 | 可 | 可 | 可（自己的） | 不可 | 不可 |
| 取消任务 | 可 | 可 | 不可 | 不可 | 不可 |
| 从阻塞恢复 | 可 | 可 | 可（自己的） | 不可 | 不可 |

SYSTEM_ADMIN 全局覆盖项目 OWNER 权限；TEACHER 全局覆盖项目只读权限。

### 5.5 项目状态对任务的限制

| 项目状态 | 创建 | 编辑 | 状态变更 | 查看 |
|---|---|---|---|---|
| PREPARING | 可 | 可 | 可 | 可 |
| ACTIVE | 可 | 可 | 可 | 可 |
| PAUSED | 不可 | 不可 | 不可 | 可 |
| COMPLETED | 不可 | 不可 | 不可 | 可 |
| ARCHIVED | 不可 | 不可 | 不可 | 可 |

### 5.6 首页 tasks 区域

- state 从 NOT_AVAILABLE → READY
- 统计字段：todo、inProgress、blocked、doneThisWeek
- list：最近 5 条任务，按 updateTime 降序
- 空状态：state=READY，计数全 0，list=[]，显示"暂无任务"
- SYSTEM_ADMIN/TEACHER 同样显示自己作为负责人的任务

### 5.7 API 接口

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/projects/{id}/milestones` | POST | 创建里程碑 |
| `/api/projects/{id}/milestones` | GET | 里程碑列表（含任务统计） |
| `/api/projects/{id}/milestones/{mid}/status` | PUT | 更新里程碑状态 |
| `/api/projects/{id}/tasks` | POST | 创建任务 |
| `/api/projects/{id}/tasks` | GET | 任务列表（分页、筛选、排序） |
| `/api/projects/{id}/tasks/{tid}` | GET | 任务详情 |
| `/api/projects/{id}/tasks/{tid}` | PUT | 编辑任务基本信息 |
| `/api/projects/{id}/tasks/{tid}/status` | PUT | 任务状态变更（乐观锁） |

### 5.8 错误响应扩展

- 400：INVALID_PARAMETER、BLOCK_REASON_REQUIRED、ASSIGNEE_NOT_MEMBER、MILESTONE_NOT_FOUND、INVALID_DUE_DATE
- 404：MILESTONE_NOT_FOUND、TASK_NOT_FOUND
- 409：VERSION_CONFLICT、TASK_INVALID_TRANSITION、MILESTONE_INVALID_TRANSITION、PROJECT_PAUSED、PROJECT_COMPLETED

### 步骤 1：创建里程碑
```bash

curl -s -X POST http://localhost:8080/api/projects/1/milestones \
```

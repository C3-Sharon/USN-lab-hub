### 已发现的技术债务

后端：

1. 鉴权范围不完整：`/admin/**` 和多数 `/api/iot/**` 未进入 JWT 拦截，无全局角色校验
2. JWT 固定默认密钥存在于配置文件，共享环境不安全
3. Token 只表达全局 roleKey，无项目角色；`operatorId=0/system` 掩盖未鉴权操作
4. 人员/考勤无回归测试（登录、JWT 解析、拦截路径、角色授权、签到签退、缓存、并发、跨日自动签退）
5. Maven Wrapper `mvnw.cmd` 3.3.4 在 PowerShell 启动失败，干净机器无法按文档复现
6. 集成测试以 H2 为主，未验证真实 MySQL 锁、唯一约束、JSON 和事务语义
7. `GlobalExceptionHandler` 未统一 HTTP 状态、业务码和校验异常语义
8. 所有代码集中在 `com.usn.labhub.user`，需按业务任务渐进迁移

前端：

1. UI_SPEC 16 个设计 Token 全部未落地，所有页面硬编码十六进制色
2. Login/Dashboard 引入 Unsplash 外链图片，违反 UI_SPEC §5/§6
3. 10 处 API 数据取值错误（API-1~API-10），真实接口下列表/详情/指标数据为 `undefined`
4. 1 处 API 参数形态不一致（API-16），需与后端约定
5. 详情页（`/iot/projects/:id`、`/iot/devices/:id`）未单独截图
6. ECharts 与 Element Plus 全量打包，主 chunk > 2.4 MB
7. 应用外壳断点 768/860/900 不统一，未针对 1280x800 与 390x844 做布局验证
8. 缺少 ErrorState/EmptyState 公共组件，错误态与空态在多页面重复实现

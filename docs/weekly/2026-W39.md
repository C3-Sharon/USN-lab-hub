# 2026-W39 周任务：正式项目档案、项目成员与项目权限契约

> 路线周次：第 3 周
> 风险：HIGH（项目权限边界 + 数据迁移 + 成员管理幂等）
> 状态：REVIEW

## 1. 本周目标

建立"创建正式项目并邀请成员"的完整契约，使成员可以从个人工作台进入自己参与的项目。冻结项目状态枚举、项目角色枚举、基础 CRUD 接口、成员管理接口和权限边界。

## 2. 明确不做

- 不实现里程碑和任务状态机（第 4 周）
- 不实现项目动态、归档交接和 Git 仓库同步
- 不实现图片上传和 MinIO，只保留可选媒体字段与默认占位
- 不修改现有 MQTT、IoT、考勤及鉴权契约
- 不把 `/iot/projects` 当作正式项目工作台（历史演示路径保留）
- 不引入微服务、Redis 缓存或复杂审批流
- 不实现项目退出、移除成员和 OWNER 转让（待确认，如确认则实现）
- 不实现项目公开可见性的完整控制

## 3. 用户与场景

### 3.1 目标用户

- **系统管理员**：创建项目、查看全部项目、管理项目成员
- **老师/实验室负责人**：创建项目、查看全部项目、指导学生项目
- **普通成员**：创建或参与项目、查看自己参与的项目
- **库存管理员**：参与项目、查看项目物料需求（第 9 周起生效）

### 3.2 主流程

1. 用户登录后进入个人工作台
2. 工作台 projects 区域显示自己参与的项目列表（state=READY）
3. 点击"创建项目"，填写编号、名称、简介、分类
4. 创建成功，自动成为 OWNER，跳转到项目详情页
5. 在项目详情页添加成员（输入学工号 + 选择角色）
6. 被添加的成员登录后，在工作台项目列表中看到新项目
7. 点击项目卡片进入项目详情页

### 3.3 失败/越权流程

- 项目编号重复 → 409 reason=PROJECT_CODE_DUPLICATE
- 非成员访问项目 → 404（不暴露存在性，待确认）
- 权限不足（如 MEMBER 尝试添加成员） → 403 reason=PROJECT_OPERATION_DENIED
- 添加不存在的用户 → 404 reason=USER_NOT_FOUND
- 重复添加成员且角色相同 → 200（幂等，返回已有成员信息）
- 重复添加成员但角色不同 → 409 reason=ALREADY_MEMBER_DIFFERENT_ROLE
- 归档项目添加成员 → 409 reason=PROJECT_ARCHIVED
- 空项目列表 → 合法空状态，不返回 mock 数据

### 3.4 前置数据

- dev 分支 commit `5ea466d`
- 现有 `lab_project` 表（V5 创建，服务 IoT 演示）
- 现有五档全局角色（V6 迁移）
- 现有个人工作台首页（state=NOT_AVAILABLE 的 projects 占位）

## 5. 冻结的契约

### 5.1 项目状态

五态：PREPARING（筹备中）、ACTIVE（进行中）、PAUSED（已暂停）、COMPLETED（已完成）、ARCHIVED（已归档）。ARCHIVED 为终态，拒绝成员变更。详见 `PROJECT_WORKSPACE_API.md` §3。

### 5.2 项目角色

四档：OWNER（项目负责人）、MAINTAINER（项目维护者）、MEMBER（项目成员）、OBSERVER（观察者）。OWNER 权限最高，OBSERVER 只读。详见 `PROJECT_WORKSPACE_API.md` §4。

### 5.3 基础接口

- `POST /api/projects` — 创建项目
- `GET /api/projects` — 项目列表（分页、过滤、排序）
- `GET /api/projects/{id}` — 项目详情（含成员列表）
- `POST /api/projects/{id}/members` — 添加成员

详见 `PROJECT_WORKSPACE_API.md` §5。

### 5.4 错误响应

- 401/403 沿用 AUTH_WORKBENCH_V1 格式，扩展项目相关 reason
- 404：PROJECT_NOT_FOUND、USER_NOT_FOUND
- 409：PROJECT_CODE_DUPLICATE、ALREADY_MEMBER_DIFFERENT_ROLE、PROJECT_ARCHIVED

详见 `PROJECT_WORKSPACE_API.md` §6。

### 5.5 工作台集成

首页 projects 区域从 state=NOT_AVAILABLE 切换为 state=READY，返回用户参与的项目列表摘要。空列表为合法空状态。

详见 `PROJECT_WORKSPACE_API.md` §7。

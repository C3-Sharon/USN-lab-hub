## 使用规则

1. 产品契约冻结并合入 `dev` 后，由后端从本模板创建 `docs/backend/execution/2026-WNN.md`。
2. 每周拆成 3 至 6 个可独立验证的工作块，同一时间只能有一个 `IN_PROGRESS`。
3. 计划内容不能作为完成证据；每块结束后必须填写实际文件、测试结果、偏差和提交号。
4. 普通工作块验证通过后可自动继续；高风险阶段门必须暂停并取得用户明确确认。
5. 本文件只记录执行状态。业务范围以当周文档为准，字段和枚举以生效契约为准，已验证系统能力以 `CURRENT_STATE.md` 为准。

# USN Lab Hub 26 周路线

> 状态值：`NOT_STARTED`、`IN_PROGRESS`、`BLOCKED`、`VERIFIED`
> `VERIFIED` 只在三个角色 PR 合入 `dev` 且周验收通过后填写。

## 延期规则

任何周未通过验收时：

1. 状态标记为 `BLOCKED`，记录失败场景和责任边界。
2. 指定恢复周和被替换的次要工作，不得只写“以后补”。
3. 下一周产品任务先说明是否影响契约；前后端不得静默绕过。
4. 第 10、17、21、24 周专项门失败时，暂停其后的依赖能力。
5. 不删除最终验收矩阵中的主链路来制造进度正常的表象。
